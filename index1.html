🤖 Quer testar a IA do Claude?
Basta instalar o projeto no seu computador: git clone https://github.com/danielmcota14-byte/cookiescript.git (repositório no GitHub). Depois rode instalar_claude_code.bat (Windows) ou instalar_claude_code.sh (Linux/Mac), execute claude uma vez para entrar na sua conta e inicie com python cookie_ide_app.py. Escolha o provedor Claude Code Local abaixo. Ele usa o CLI do seu computador, então não funciona em versões hospedadas na internet.

Memória ativa · sem geração de imagens · arquivos suportados

A IA não gera imagens. Quando criar arquivos, use os botões Baixar na resposta para salvar no seu PC.

Resposta da IA

Escolha um provedor, insira a chave (se necessário) e envie sua pergunta.
Claude Code Local usa o CLI claude já instalado/autenticado no seu computador (sem chave de API extra).
DeepSeek Local usa torch + transformers direto no servidor (sem internet, sem API).
Gemini e Groq requerem chave API gratuita (opcional).
